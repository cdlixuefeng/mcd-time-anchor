## V2EX / 掘金 / 知乎（技术向）

标题候选：
1. 我用麦当劳 MCP 写了个点餐 Skill，顺手把「平行宇宙」也实现了
2. 给麦当劳 MCP 补三个短板：门店路由、省钱组合、长期记忆
3. 一个纯提示词的点餐 Skill 是怎么做出「越用越懂你」的

正文：

> 参加了麦当劳的程序员创意开发大赛，基于麦当劳公开 MCP 做了这个东西：**麦味时光锚点**。
>
> 三个能力：
> - **老样子极速单**：说「老样子」完成搜店→比券→凑单→下单，价格和省钱额全部走 `calculate-price` 实算
> - **时光锚点**：每次点餐沉淀一条记忆。但要经过 `query-order` 对账确认真实支付才入档——取消的单不进档案，不做假数据
> - **平行宇宙**：从真实锚点交叉推演「另一种点餐人生」，全部标注推演，数据可实算复现
>
> 过程中踩到的有意思的点：
> - MCP 的 `query-nearby-stores` 支持 city+keyword 直接搜「春熙路」，**压根不需要地图 API**，基础版零外部依赖
> - 官方文档的订单状态枚举和实际返回对不上（文档说待支付=1，实际是 `orderStatus:"待支付"` + `status:"10"`），对账逻辑只能容错
> - `calculate-price` 返回单位是分，订单接口是元——混用必炸
>
> 附了个零依赖单文件可视化器，双击就能看你自己的点餐时光档案。
>
> 项目：https://github.com/cdlixuefeng/mcd-time-anchor
> 觉得有意思的话给个 Star ⭐（比赛按 Star 排名）
